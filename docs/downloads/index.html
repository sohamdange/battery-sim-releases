    Install, activate, update

    01

    Install

    Run the installer and follow the steps. Everything the app needs is included, so there is nothing else to set up.

    02

    Activate

    Request a free key, then enter it in the app with the same email address. The key locks to the first computer it is activated on.

    03

    Stay up to date

    The app tells you when an update is available and installs it for you. Your data is backed up automatically first.

    Your first simulation, step by step {% include icon.html name="arrow" px=16 %}

    An update did not finish. What now?

    Open the app and use the Repair option, which re-runs the installer from inside the app. Since 0.1.8 the app also detects when only part of an update was installed. An installed add-on is kept through updates. You can also download the installer above and run it over the existing installation.

    Where is my data stored?

    In a BatterySimSuite folder in your Windows user directory. Nothing is uploaded. See the privacy policy.

    Can I use it without internet?

    Simulations run fully offline. The licence is checked when the app starts, and a short-lived offline token covers brief outages. The add-on can be installed from a file on offline computers.

    Something else is wrong

    Get in touch with your app version (Settings → About), your Windows version and what happened.
