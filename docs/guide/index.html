Install the app and activate it

About a minute from download to the app opening with its examples ready.

Download · Install · Get a key · Activate

  1. Download the installer from the Downloads page (about 127 MB, everything bundled).
  2. Run it. Windows may warn that the publisher is unknown, because the installer is not code-signed yet. Check the file name, then click Run (or More info, then Run anyway). Why Windows warns, and how to check the file.
  3. Click through the installer: accept the licence agreement and keep the default folder. No administrator rights are needed.
  4. Get a free licence key on the licence page. It is emailed to you in a few seconds. Free, no expiry, every feature included.
  5. Start the app, enter the same email and the key, and click Activate. It opens with the examples ready.

// Part 2 · Your first simulation

Your first simulation, step by step

Each step builds a reusable piece of your library, so the next study starts further along. A simulation combines a pack (built from one cell) with a simulation cycle (the load it sees, day by day). The load is built in four levels, so nothing is duplicated.

  1. STEPSSequenceCurrent, power or rest steps, e.g. 1 C discharge to 3.0 V
  2. ONE DAYDay profileSequences in order, up to 24 hours
  3. ONE YEARYear profileRules that assign day profiles to days
  4. YEARSSimulation cycleYear profiles in order, each repeated
  1. 01

    Add a cell

    In the app: Cell Library → Add a cell

    A cell holds its identity, dimensions and voltage limits. Fill in the name, nominal voltage and capacity first. Then add a configuration: the physics to run it with.

    • {% include icon.html name="check" px=18 %}Circuit model: download the RC template CSV, fill in your measured SOC, OCV, R0 and RC values for each temperature, and upload it. It is checked as it uploads.
    • {% include icon.html name="check" px=18 %}Electrochemical model (with the add-on): enter the cell’s electrochemical parameter block, and record where the values came from.

    Common mistake: RC data at only one temperature. The solver interpolates between temperatures, so a single point gives wrong results elsewhere. If that is all you have, set a generous temperature extrapolation tolerance.

    {% include shot.html id="cell-builder" %}
  2. 02

    Build a pack

    In the app: Pack Builder

    Choose the cell, then arrange cells in layers using a rectangular or diagonal layout. Pick how they are wired (column-parallel, row-parallel or custom groups) and set the series and parallel link resistances. The builder shows the layout and the resulting voltage, capacity and energy as you edit.

    For a thermal study, check the cell-to-cell thermal connections and set cooling to the air or a coolant plate.

    Common mistake: mixing up column-parallel and row-parallel. The name says which direction is in parallel, not which is in series.

    {% include shot.html id="pack-builder" %}
  3. 03

    Create sequences

    In the app: Simulation Scenario Builder → Sequence Library

    A sequence is a list of steps: charge, discharge or rest, in current, C-rate, power or voltage, for a set time, or until a trigger such as a cell voltage or pack SOC fires. Build them in the table, or import a recorded load from CSV or Excel.

    Common mistake: no rest between charge and discharge. Real cells need rest for their voltage to relax.

    {% include shot.html id="sequence-builder" %}
  4. 04

    Assemble the schedule

    In the app: Simulation Scenario Builder

    Chain sequences into a day profile: one day of use, up to 24 hours, each sequence at its own ambient temperature. Then create a year profile and use its Calendar tab to assign day profiles to days, for example weekdays commute, weekends highway, with a default for every other day. Finally put one or more year profiles in order in a simulation cycle, each repeated as many times as you need: one year, or a heavy first year followed by nine lighter ones.

    Common mistake: conditions on one rule combine with AND. Months = January and Days = Monday fires only on Mondays in January. The first matching rule wins, so order rules from most to least specific.

    {% include shot.html id="simulation-cycle" %}
  5. 05

    Configure and run

    In the app: Simulations

    Select the pack and the simulation cycle. Choose the model first, then the cell configuration, then set the starting SOC and cell temperature. Optionally switch on the thermal model, give cells their own capacity and resistance spread, set voltage limits, add end triggers such as a state of health for long ageing studies, and choose what the run records.

    Runs show live progress. You can run several side by side (they share the computer's processor), and stop one at any point while keeping the results so far.

    Common mistake: a high starting SOC with a charge-heavy schedule. The run stops at the upper voltage cut-off soon after it starts.

    {% include shot.html id="simulation-setup" %}
  6. 06

    Read the results

    In the app: Simulations → open a run

    Start with end SOC and peak temperature, then explore the pack, cell, overlapping and spatial views. Electrochemical runs with ageing add an Ageing panel. Export the time series to CSV, or create a PDF report.

Install the Electrochemical Models Add-On

Four PyBaMM-based cell engines (Thevenin, SPM, SPMe and DFN), free with any licence. What the add-on does.

From inside the app

  1. Open Settings → About in Battery Sim Suite.
  2. Click Install. The app downloads the add-on and checks it before unpacking.
  3. Pick an engine when you set up a simulation.

The app refuses any file whose size, checksum or listing does not match.

No internet? Install from a file

  1. On a connected computer, download the add-on zip and its .json listing from the Downloads page.
  2. Copy both files to the offline computer.
  3. Choose Install from file in Settings → About and select both.

The add-on is not code-signed. The SHA-256 checksums on the Downloads page are how to confirm a copy is genuine.

Settings → About shows whether the add-on is installed, its version, and Install or Uninstall. Updates to the app keep an installed add-on.

// FAQ

Questions while getting started

Why is the Run button disabled?

It needs both a pack and a simulation cycle selected. If both are, check that the pack has a valid cell and that a model and cell configuration are chosen.

What format do RC parameters need?

Use the template from the Cell Builder rather than writing one from scratch. Columns are named by direction and temperature, such as CHARGE_T25_soc or DISCHARGE_T05_r0, and each temperature needs both a charge and a discharge block. SOC must rise from row to row. A table that stops short of 0 % or 100 % is extended in a straight line, shown dashed in the plots.

Does the app include standard drive cycles?

No. Build your own from steps, or import a recorded load from CSV or Excel as a sequence.

Can a pack mix different cells?

A pack uses one cell type. To study cell-to-cell differences, give each cell its own capacity and resistance factors in the simulation setup: typed, imported from CSV, or drawn from a measured spread with a repeatable seed.

Which model should I start with?

The built-in equivalent-circuit model: it is the fastest and needs only RC tables. Move to SPM, SPMe or DFN when you need diffusion limits, electrolyte effects or ageing. See the engines.

Is every loss counted as heat?

Not yet. Pack link resistance, cell contact resistance on the electrochemical models, and SEI film resistance lower the voltage correctly but are left out of reported heat. Each affected run’s log carries a warning.

Can I run several simulations at once?

Yes. Each run is independent, though they share your computer’s resources, so several heavy runs will each be slower.
