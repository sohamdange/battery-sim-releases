// 01 · Cell Library

A reusable catalogue of characterised cells

Define each cell once and reuse it in every pack and study.

  • {% include icon.html name="check" px=18 %}Capacity, OCV curve, voltage limits, coulombic efficiency and optional entropic heat
  • {% include icon.html name="check" px=18 %}RC tables with 1, 2 or 3 RC pairs per temperature, from a downloadable CSV template that is checked on upload
  • {% include icon.html name="check" px=18 %}Named configurations: run one physical cell as a circuit model, an electrochemical model, a baseline or an ageing study
  • {% include icon.html name="check" px=18 %}Cylindrical, prismatic, pouch and coin form factors
  • {% include icon.html name="check" px=18 %}A references field to record where each model came from
  • {% include icon.html name="check" px=18 %}Cell preview with tabs, a KPI strip, voltage plots and an RC parameter grid
  • {% include icon.html name="check" px=18 %}Search, sort by any property and filter by form factor

// 02 · Pack Builder

Any series and parallel layout

Arrange cells in layers, wire them in series and parallel, and let the app work out the pack’s voltage, capacity and limits.

  • {% include icon.html name="check" px=18 %}Rectangular or diagonal cell layouts, stacked in multiple layers, with 2D and 3D previews
  • {% include icon.html name="check" px=18 %}Column-parallel, row-parallel or custom parallel groups
  • {% include icon.html name="check" px=18 %}Connections laid out for you; you set the series and parallel link resistances
  • {% include icon.html name="check" px=18 %}Thermal connections between neighbouring cells, worked out from their positions and editable
  • {% include icon.html name="check" px=18 %}Export cell coordinates, thermal links and the cooling map
  • {% include icon.html name="check" px=18 %}Pack Library with search, sorting and form-factor filter

// 03 · Drive cycles & schedules

Real cycles, mapped onto a real year

Go beyond a single test profile. Build up the way a pack is actually used, from single steps to a full calendar.

  • {% include icon.html name="check" px=18 %}Sub-cycles: current, power or rest steps, or steps that end on a voltage or SOC condition
  • {% include icon.html name="check" px=18 %}Import a recorded schedule from CSV or Excel as a sub-cycle
  • {% include icon.html name="check" px=18 %}Drive cycles: sub-cycles chained into one day of use, up to 24 hours
  • {% include icon.html name="check" px=18 %}Simulation cycles: calendar rules by month, weekday or date, with a default for every other day
  • {% include icon.html name="check" px=18 %}Sub-cycle, drive-cycle and simulation-cycle libraries with search and sorting

// 04 · RC equivalent-circuit solver

Every cell, solved individually

The built-in solver models each cell in the pack on its own, with no lumped approximation, and balances the current between cells wired in parallel.

  • {% include icon.html name="check" px=18 %}Per-cell current, voltage, SOC and temperature
  • {% include icon.html name="check" px=18 %}Simple R0-only model, or the full RC ladder from your tables
  • {% include icon.html name="check" px=18 %}Cell-to-cell variation: give each cell its own capacity and resistance, typed, imported from CSV, or drawn from a measured spread with a repeatable seed
  • {% include icon.html name="check" px=18 %}Unbalanced parallel branches handled, with a high-precision option when the imbalance is what you are studying

// 05 · Pack thermal model

Heat that moves through the pack

Switch on the thermal model and every cell warms from its own losses, passes heat to its neighbours and sheds it to the air or a coolant plate.

  • {% include icon.html name="check" px=18 %}Cell self-heating from resistive, RC and optional entropic heat
  • {% include icon.html name="check" px=18 %}Heat flows between linked cells through the pack’s thermal connections
  • {% include icon.html name="check" px=18 %}Cooling to the air, with its temperature taken from the drive cycle, and to a coolant plate at a set temperature
  • {% include icon.html name="check" px=18 %}Cooling set per group of cells, with per-cell overrides, so a large pack needs only a few numbers
  • {% include icon.html name="check" px=18 %}Works with every cell model, built-in and add-on

// 06 · Simulation Library

Every run, tracked

Run studies, follow their progress and come back to any result later.

  • {% include icon.html name="check" px=18 %}Run several simulations at once, with live status and progress
  • {% include icon.html name="check" px=18 %}Stop a run at any point and keep the results so far
  • {% include icon.html name="check" px=18 %}Choose what each run records, for smaller files and faster runs
  • {% include icon.html name="check" px=18 %}Every result records the model and settings that produced it
  • {% include icon.html name="check" px=18 %}Readable logs that say what each step is doing, and why a run stopped

// 07 · Results & analysis

From pack totals to a single cell

Full traces are stored in HDF5 and plotted inside the app. Export them when you need to take them further.

  • {% include icon.html name="check" px=18 %}Voltage, current, SOC, heat and temperature traces
  • {% include icon.html name="check" px=18 %}Pack-level, cell-level, overlapping views, and a spatial heatmap across the pack
  • {% include icon.html name="check" px=18 %}End SOC and peak temperature summaries, and an Ageing panel on electrochemical runs
  • {% include icon.html name="check" px=18 %}Export to CSV for Excel, Python or MATLAB, or as a PDF report

// 09 · Platform

A desktop app that looks after itself

{% include icon.html name="lock" %}

Offline and local-first

No cloud, and no internet needed to run simulations. Every model, configuration and result is stored on your computer.

{% include icon.html name="windows" %}

One installer

Python, runtimes and every library are bundled. There is nothing else to install on Windows 10 or 11.

{% include icon.html name="refresh" %}

Safe in-app updates

Updates are signature-checked before they install, wait for the simulation engine to stop, and detect a half-finished update.

{% include icon.html name="shield" %}

Repair, built in

If an update does not finish, a Repair option re-runs the installer from inside the app.

{% include icon.html name="doc" %}

Automatic backups

Your data is backed up automatically when the app changes version, before anything new touches it.

{% include icon.html name="key" %}

Clear licensing

A signed licence file keeps the app working through short outages. The expiry date is shown in Settings, with advance warning.
