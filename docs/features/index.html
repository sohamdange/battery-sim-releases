// 01 · Cell Library

A reusable catalogue of characterised cells

Define each cell once and reuse it in every pack and study.

  • {% include icon.html name="check" px=18 %}Capacity, OCV curve, voltage limits and RC network parameters
  • {% include icon.html name="check" px=18 %}Tabular RC data per temperature, uploaded from CSV
  • {% include icon.html name="check" px=18 %}Cylindrical, prismatic, pouch and coin form factors
  • {% include icon.html name="check" px=18 %}A references field to record where each model came from
  • {% include icon.html name="check" px=18 %}Cell preview with tabs, a KPI strip, voltage plots and an RC parameter grid
  • {% include icon.html name="check" px=18 %}Search, sort by any property and filter by form factor

  • {% include icon.html name="check" px=18 %}Automatic busbar resistance calculation
  • {% include icon.html name="check" px=18 %}Geometry-aware cell classification
  • {% include icon.html name="check" px=18 %}Pack electrical properties derived from the selected cell
  • {% include icon.html name="check" px=18 %}Pack Library with search, sorting and form-factor filter

// 03 · Drive cycles & schedules

Real cycles, mapped onto a real year

Go beyond a single drive cycle. Compose the way a pack is actually used, day by day.

  • {% include icon.html name="check" px=18 %}Standard cycles such as WLTP and UDDS, or your own
  • {% include icon.html name="check" px=18 %}Multi-step schedules with sub-cycle extraction
  • {% include icon.html name="check" px=18 %}Calendar rules that map cycles to days across a full year
  • {% include icon.html name="check" px=18 %}Sub-cycle, drive-cycle and simulation-cycle libraries with search and sorting

// 04 · RC equivalent-circuit solver

Every cell, solved individually

A KCL-based solver models each cell in the pack on its own, with no lumped approximation.

  • {% include icon.html name="check" px=18 %}Per-cell current, voltage, SOC and temperature
  • {% include icon.html name="check" px=18 %}Handles unbalanced parallel branches
  • {% include icon.html name="check" px=18 %}Mixed cell types within the same pack
  • {% include icon.html name="check" px=18 %}Compiled with Cython for speed

// 05 · Simulation Library

Every run, tracked

Run studies, follow their progress and come back to any result later.

  • {% include icon.html name="check" px=18 %}Status badges and progress bars for running simulations
  • {% include icon.html name="check" px=18 %}End SOC and peak temperature in the list
  • {% include icon.html name="check" px=18 %}Clickable rows that open results directly
  • {% include icon.html name="check" px=18 %}Readable simulation logs with trigger descriptions

// 06 · Results & analysis

From pack totals to a single cell

Full traces are stored in HDF5 and plotted inside the app, without exporting anything.

  • {% include icon.html name="check" px=18 %}Voltage, current, SOC and temperature traces
  • {% include icon.html name="check" px=18 %}Pack-level, cell-level, spatial and overlapping views
  • {% include icon.html name="check" px=18 %}End SOC and peak temperature summaries
  • {% include icon.html name="check" px=18 %}Unit controls on every plot

// 08 · Platform

A desktop app that looks after itself

{% include icon.html name="lock" %}

Offline and local-first

No cloud, and no internet needed to run simulations. Every model, configuration and result is stored on your computer.

{% include icon.html name="windows" %}

One installer

Python, runtimes and every library are bundled. There is nothing else to install on Windows 10 or 11.

{% include icon.html name="refresh" %}

Safe in-app updates

Updates are signature-checked before they install, wait for the simulation engine to stop, and detect a half-finished update.

{% include icon.html name="shield" %}

Repair, built in

If an update does not finish, a Repair option re-runs the installer from inside the app.

{% include icon.html name="doc" %}

Automatic backups

Your data is backed up automatically when the app changes version, before anything new touches it.

{% include icon.html name="key" %}

Clear licensing

The expiry date is shown in Settings with advance warning, and a licence-server outage is never mistaken for an invalid key.
