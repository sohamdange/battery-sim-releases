// What you can study

More than a single cell on a test bench

The add-on engines plug into the same pack, schedule and results pipeline as the built-in model, so everything else in the app works with them.

{% include icon.html name="pack" %}

Whole packs

Run every cell of a pack on SPM, SPMe or DFN, including cells wired in parallel, which share the load as their states drift apart.

{% include icon.html name="refresh" %}

Cell ageing

Switch on SEI growth, lithium plating or swelling in a cell configuration. Ageing feeds back into the run as it happens, through lost capacity and added resistance.

{% include icon.html name="chart" %}

State of health over time

Every 10 simulated minutes the run records each cell’s state of health, capacity, lithium lost, active material lost and SEI thickness, shown in an Ageing panel and the PDF report.

{% include icon.html name="bolt" %}

Thermal, on every engine

The pack thermal model works with the add-on engines too: heat from neighbouring cells becomes each PyBaMM cell’s surroundings.

{% include icon.html name="cell" %}

Your own parameters

Enter a cell’s electrochemical parameter block in the Cell Builder, with a references field for where the numbers came from, such as Chen et al. 2020.

{% include icon.html name="shield" %}

Comparable results

Every result records the engine, solver (IDAKLU or CasADi) and cell configuration that produced it, so two runs can be compared knowing exactly what made each.

// Install

Installs from inside the app

  1. Open Settings → About in Battery Sim Suite.
  2. Click Install. The app downloads the add-on and checks it before unpacking.
  3. Pick an engine when you set up a simulation.

The app refuses any file whose size, checksum or listing does not match.

// Offline computers

No internet? Install from a file

  1. On a connected computer, download the add-on zip and its .json listing from the Downloads page.
  2. Copy both files to the offline computer.
  3. Choose Install from file in Settings → About and select both.

The add-on is not code-signed. The SHA-256 checksums on the Downloads page are how to confirm a copy is genuine.
