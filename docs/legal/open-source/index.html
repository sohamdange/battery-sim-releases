Battery Sim Suite is built with open-source software. Each part keeps its own licence, and this page explains where to find them.

The application

The full list of open-source components in the app, with their licence texts, is in the app under Settings → Licences.

Electrochemical Models Add-On

The add-on uses PyBaMM. It is not affiliated with or endorsed by the PyBaMM team.

The add-on bundles open-source software, each part under its own licence. The full list is in THIRD_PARTY_NOTICES.txt inside the add-on, and in the app under Settings → Licences.

Source code for the LGPL parts. Each add-on release includes a sources zip with the exact source code of CasADi (LGPL) and of the solver parts shipped with it: pybammsolvers, SUNDIALS, SuiteSparse KLU and the GCC runtime. It is on the Downloads page.

CasADi ships as its own folder of unmodified files (_internal\casadi), so it can be replaced with your own build of the same CasADi version (3.7.2 for add-on 11.0).
